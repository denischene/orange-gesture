# Orange Gesture Revival

La pièce jointe est une ancienne extension Firefox nommée ogc pour « Orange Gesture Control» ou en Français «Commande gestuelle d’Orange». Identifie les éléments la composant et propose une restructuration afin qu’elle puisse fonctionner sur la dernière version de Firefox.
