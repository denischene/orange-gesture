*** Add File: extension/README.md # Orange Gesture Control — WebExtension (MV3) Modern Firefox port of the legacy XUL/XPCOM extension `ogc@orange-ftgroup.com`. ## Structure ``` extension/ ├── manifest.json # MV3 manifest (replaces install.rdf + chrome.manifest) ├── background/ │ └── service_worker.js # Action dispatcher (replaces XPCOM component) ├── content_scripts/ │ ├── gestures.js # Pointer capture + sequence dispatch │ ├── trails.js # Canvas overlay (replaces OGC_Trails.js) │ ├── tooltips.js # Floating label (replaces OGC_Tooltips.js) │ ├── long_click.js # Long-click detector (replaces OGC_LongClick.js) │ └── ogc.css # Overlay styles (replaces accessibility CSS) ├── lib/ │ ├── recognizer.js # 8-direction tokenizer (replaces native C++ engine) │ └── vocabulary.js # Sequence → action map (replaces RDF vocabulary) ├── options/ # options_ui (replaces OGC_Option.xul) ├── popup/ # browser_action popup ├── sidebar/ # sidebar_action (replaces OGC_Sidebar.xul) └── _locales/{en,fr}/messages.json # Replaces DTD locales ``` ## Install (temporary, for development) 1. Open `about:debugging#/runtime/this-firefox` 2. Click **Load Temporary Add-on…** 3. Select `extension/manifest.json` ## Package ```bash cd extension && zip -r ../ogc.xpi . ``` ## Known limitations vs. legacy version - Gestures cannot run on `about:`, `addons.mozilla.org`, or `view-source:` pages (browser policy). - The native C++ recognizer was replaced by an 8-direction JS tokenizer; for 1:1 stroke matching, port the original engine to WebAssembly. - `nsIPrefBranch` preferences are migrated to `browser.storage.local` (one-time migration not included). - Right-button gesture suppresses the context menu only when a non-empty sequence is recognized.
